# Exercises setup

Set up an `exercises.md` for a particular chapter.
These will be the exercises as written in the text verbatim, converted into markdown format.

## Example

This is an example snippet of the file you would generate for Exercises 1B in Linear Algebra Done Right by Axler:

`ch01/exercises.md`:
```
# Exercises 1A, page 10

1. Show that α + β = β + α for all α, β ∈ 𝐂.

<!-- pending -->

2. Show that (α + β) + λ = α + (β + λ) for all α, β, λ ∈ 𝐂.

<!-- pending -->

...

# Exercises 1B, page 16

1. Prove that -(-v) = v for every v ∈ V.

<!-- pending -->

2. Suppose that a ∈ 𝐅, v ∈ V, and av = 0. Prove that a = 0 or v = 0.

<!-- pending -->

...
```
